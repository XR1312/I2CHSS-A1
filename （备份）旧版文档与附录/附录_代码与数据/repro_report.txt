  说明 1：本表第 7 列 CAIC 与 SI 表 C2 中名为 "AIC" 的那一列（1380 / 979 / 998 / 1035 …）逐格相同。
          原因是脚本这两行把 CAIC 存进了名为 AIC 的列：
            CAICs <- (-2*lc$llik) + lc$npar * (1 + log(lc$N))
            data.frame(loglik, Df, BIC, aBIC, AIC = CAICs, Gsq = lc$Gsq)
          真正的 AIC = −2ll + 2·npar 在 K=5 才取到最小（825.6），K=3 时是 846.0。
  说明 2：K=1–4 与 SI 表 C2 在四舍五入到整数后逐格相同；K≥5 的差异见 [4]。

  各准则的最小解：BIC→K=2   aBIC→K=10   CAIC（论文标为 AIC）→K=2   真 AIC→K=5
  而脚本自己的选择规则是 if(lc$bic < min_bic)，会把 K=2 存成 LCA_best_model；论文正文报告的却是 3 类解。
